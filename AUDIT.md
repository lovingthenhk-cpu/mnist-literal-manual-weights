# Model-compliance and evaluation audit

## Constraint adherence

- This repository is an independent fresh start. The older `/mnist-direct-weight-edit-experiments` and its 99.02% are **INVALID** for this experiment.
- The assistant authored literal numeral path coordinates, class biases, morphology weights, endpoint targets, horizontal crossing targets, branch targets and global geometry targets, all in source under `src/manual_shapes.py` and `src/model.py`.
- The code rasterizes literal handwritten glyph path coordinates into 28×28 numerical arrays, with 8,424 deterministic affine variations. This is not a learned prototype dictionary; no actual MNIST image is stored in a template.
- Geometry and topology features are computed only from **the image being classified**. No reference MNIST samples or their labels are used at prediction time.
- NO gradient descent, SGD, Adam, autograd, backpropagation, evolutionary algorithm, numerical optimizer, parameter fitting, trained centroids, learned kernel, or pretrained model exists.
- Labels in the MNIST training split were inspected to evaluate and diagnose mistakes. Model corrections were typed manually, not auto-generated by minimization of an objective.
- Dataset copied only into the ignored `data/mnist.npz`; repository contains all **generated model weights**, not raw MNIST training images.
- Experiment 019 holds two complete compiled numerical weight sets, and their fixed 1:1 equal-weight blend. This is not fitting an ensemble mixing coefficient; `0.5` and `0.5` were directly specified.
- `scripts/evaluate_ensemble.py` never reads prior `evaluation.npz` files or training labels during predictions. It recomputes scores from saved `weights.npz` matrices.

## Dataset protocol

- Development evaluation: MNIST train set, sample `np.random.default_rng(20261105).permutation(60000)[:2000]`.
- Official test set: the disjoint 10,000-image MNIST `x_test`, untouched throughout experiments 001–019 development tuning.
- A single final official test-set evaluation is authorized **only after** model 019 code and coefficients have been fixed and committed.
- All experiments have `experiments/expNNN/weights.npz`, `evaluation.npz`, `metrics.json`, and diagnostic misclassified images rendered in text form. Complete GitHub PR history documents each change and rollback.
